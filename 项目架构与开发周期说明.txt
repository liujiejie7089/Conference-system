🚀 AIOA - 企业级 AI Agent 智能办公基座平台
📖 项目简介
AIOA (AI Office Assistant) 是一个企业级的 AI Agent 智能基座平台。它的核心使命不是替代现有的业务系统，而是作为 “AI 能力中枢”，让公司内部的各类后台管理系统（如票务、调度、CRM、ERP 等）能够以“即插即用”的方式接入，从而自动获得强大的 AI 交互与自主执行能力。
通过 AIOA，企业员工无需再在复杂的系统菜单中寻找功能，只需通过自然语言对话，AI 助手即可自动跨系统查询数据、执行 CRUD 操作，甚至协同多个“数字员工”完成复杂的审批与业务流转。
✨ 核心特性
🔌 标准化统一接入：业务系统无需深度改造，只需提供标准 API 文档，平台即可自动将其转化为 AI 可调用的“技能”。
🧠 多智能体协作 (Multi-Agent)：支持复杂任务的拆解与编排，多个专属 Agent（如差旅 Agent、审批 Agent）可协同工作。
💬 前端无缝嵌入：提供标准化的 Vue ChatBox 组件，业务系统引入几行配置即可拥有完整的 AI 对话界面。
🔒 企业级安全与审计：统一身份认证，细粒度权限控制，所有 AI 操作与 API 调用全链路留痕，确保数据不越权。
💰 精细化计费与运营：内置词元 (Token) 计量与额度扣减模型，支持多租户/部门级别的成本核算。
🏗️ 系统架构设计
平台采用 “分层解耦、AI 核心” 的架构设计，自下而上分为五层：
1. 接入与交互层 (用户入口)
嵌入式 ChatBox：基于 Vue 开发的轻量级对话组件，支持全屏、侧边栏、悬浮球等多种形态，嵌入各业务系统。
IM 渠道网关：对接钉钉、飞书、企业微信等即时通讯工具，实现消息互通。
2. API 网关与安全层 (流量枢纽)
统一网关：所有前后端请求的统一入口，负责路由转发、限流降级。
统一认证中心 (SSO)：对接企业现有账号体系，实现单点登录与 Token 颁发。
安全审计：拦截所有 AI 发起的业务操作，进行权限校验与操作日志记录。
3. 智能体运行层 (AI 大脑)
Agent Runtime：智能体的生命周期管理，负责上下文维护、记忆管理与多轮对话状态机。
多 Agent 编排引擎：支持基于状态机和 LLM 双轨驱动的工作流，处理复杂任务的拆解、分发与结果汇总。
DeepSeek Harness 引擎 (Sidecar 模式)：作为独立的微服务运行，专门负责大模型推理、意图识别、Function Calling 路由等核心 AI 逻辑，与主业务系统技术栈解耦。
4. AI 能力与连接层 (AI 手脚)
通用连接器引擎 (Universal Connector Engine)：系统的核心枢纽。动态解析业务系统的 API 定义，自动生成标准化的 Tool（工具），并处理鉴权注入与数据清洗。
技能注册中心：管理所有已接入的业务系统能力，维护工具清单与参数 Schema。
知识库服务 (RAG)：对接企业文档库，提供向量化检索增强，让 Agent 具备企业私有知识问答能力。
5. 平台底座层 (基础设施)
运营计费服务：Token 消耗统计、部门额度管理、账单生成。
基础数据服务：租户管理、用户管理、角色权限 (RBAC)。
🔌 业务系统接入指南
为了让其他系统（如票务系统、调度系统）快速接入，我们制定了极简的接入规范：
后端接入：能力注册
提供 API 描述：业务系统开发人员只需提供标准的 OpenAPI (Swagger) 文档，或按照平台规范填写一份 JSON 格式的“技能说明书”。
平台自动解析：AIOA 管理后台接收文档后，通用连接器引擎会自动解析出接口地址、请求参数和返回值结构。
转化为 AI 技能：平台将这些接口自动注册为 Agent 可调用的“工具 (Tools)”。
安全调用：当 Agent 决定调用该工具时，连接器引擎会自动将当前用户的身份 Token 注入到请求头中，确保业务系统能进行准确的权限校验。
前端接入：界面嵌入
引入组件：业务系统前端项目引入 AIOA 提供的 Vue ChatBox 组件。
传入凭证：在组件初始化时，传入当前用户的 SSO Token 和所属系统标识。
获得能力：组件自动连接 AIOA 基座，用户即可在当前页面与 AI 对话，AI 自动具备该业务系统及其他已接入系统的能力。
🛠️ 技术选型
后端基座：Java (Spring Boot / Spring Cloud) —— 保证企业级应用的稳定性、高并发与生态成熟度。
前端框架：Vue 3 + TypeScript —— 用于开发管理后台及可嵌入的 ChatBox 组件。
AI 推理引擎：DeepSeek Harness (Python) —— 采用独立微服务部署，利用其强大的 Agent 编排与工具调用能力。
大模型接入：DeepSeek API (云端) / 支持后续扩展接入私有化部署的开源大模型。
数据存储：
业务与关系型数据：PostgreSQL
向量与知识库数据：Milvus 或 pgvector
缓存与消息队列：Redis / RabbitMQ
部署方案：Docker + Kubernetes (K8s)，支持全量私有化部署与弹性伸缩。
🗺️ 研发路线图 (Roadmap)
项目采用“场景牵引、小步快跑”的策略，分为三个主要阶段：
Phase 1: P0 核心闭环 (0-6 个月)
目标：跑通最小可行性产品 (MVP)，验证核心链路。
完成 Java 基座核心服务搭建（网关、认证、计费）。
实现单 Agent 基础问答与单技能调用 (CRUD)。
完成 Vue ChatBox 前端嵌入组件开发。
跑通 1-2 个试点业务系统（如票务查询、员工信息查询）的接入。
完成 2 周 PoC 技术验证（流式会话、基础工作流、Token 计量）。
Phase 2: P1 协作深化 (6-12 个月)
目标：支持复杂业务流程，实现真正的“自主执行”。
上线多 Agent 协作机制与可视化工作流编排引擎。
引入“人工审批 (HITL)”节点，支持需要人工确认的敏感操作。
完善通用连接器引擎，支持更复杂的 API 协议与数据清洗。
接入更多核心业务系统（如调度系统、财务系统），实现跨系统任务流转。
Phase 3: P2 生态开放 (12-24 个月)
目标：平台化演进，构建内部 AI 生态。
开放开发者平台，支持业务系统开发人员自主创建和发布“技能”。
建立内部“技能市场”与“专家（Agent）市场”。
完善多租户隔离与 SaaS 化计费体系，支持向外部客户输出能力。
🚢 部署与运维
私有化部署：提供完整的 Helm Charts 和 Docker Compose 编排文件，支持在企业内网离线环境一键部署。
高可用设计：核心服务无状态化设计，支持 K8s 水平自动扩缩容；AI 推理引擎支持 GPU 资源独立调度。
可观测性：集成 Prometheus + Grafana 进行系统监控，接入全链路追踪 (如 SkyWalking)，实现 AI 对话与 API 调用的端到端日志审计。
